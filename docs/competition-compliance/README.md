## Read this first

The repository contains substantive implementation, media planning, documentation,
and commits dated **2026-09-28 through 2026-10-01**. The official [NASA Space Apps
2026 page](https://www.spaceappschallenge.org/2026/) states that the event takes
place on **14–15 November 2026**. An official local-event guidance page also warns
that teams must not begin developing the solution intended for submission before
the official start. Therefore this existing repository must **not** be described as
having been built during the event, and its history must not be rewritten or hidden.

Before submitting any related work, obtain a written decision from the Bangladesh
local lead on whether this project is eligible, whether it must be rebuilt during
the event, and what (if any) pre-event artefacts may be used. Until then, the safe
position is: use it only as a learning/reference project and build the intended
competition submission afresh during the official event window.

## Rules hierarchy

1. The current official [NASA Space Apps site](https://www.spaceappschallenge.org/),
   its [legal/rules page](https://www.spaceappschallenge.org/legal/), and the
   registered local event lead are authoritative.
2. The user-provided Bangladesh registration site is a local registration source:
   [nasaspaceappsbd.com/registration](https://www.nasaspaceappsbd.com/registration).
3. Participant-guide documents, WhatsApp groups, NotebookLM, and an AI build guide
   can help with logistics, but do not override the official rules or a local lead's
   written instruction.

## Non-negotiable disclosure standard

- Cite every external source and state each licence.
- Keep copyright/licence notices and required attribution visible.
- Label simulations, generated data, AI footage, and synthetic narration.
- Do not claim NASA endorsement, clinical validation, a medical device, or a real
  sensor measurement when it is only a model, contract, or camera proxy.
- Do not falsify dates, Git history, team roles, source provenance, or test results.
